# Лабораторная работа №4: Отчёт

## Структура работы

- `settings.json` - файл параметров

- `main.py` - основной исполняемый модуль.
- `hashing.py` - модуль со вспомогательными функциями
- `ui.py` - модуль с графическим пользовательским интерфейсом

- `unit_tasting.py` - набор unit-тестов для модуля `hashing.py`
- `collisions.py` - функции для поиска коллизий хэш-функций

## Использование приложения

Запуск производиться из `main.py`. Аргументы командной строки: "-s", "--settings" (опционально) - Путь до файла с параметрами.

### Интерфейс

#### *1 панель меню с 1 пунктом.*

- ***"Файл"->"Загрузить":*** Позволяет выбрать любой файл, чтобы открыть его внутри программы. Если содержимое является текстом, то оно отобразиться в текстовом поле.

#### *2 кнопки*

- **"Вычислить хэш"** - Вычисляет значение хэш-функции для этого файла и отображает его.

- **"Сравнить хэш"** - Вычисляет значение хэш-функции для этого файла и сравнивает его с имеющимся в базе контрольных сумм; затем выводит уведомление с результатом; если файла в базе нет, сохраняет туда его текущий хеш.

## Unit-тесты

Модуль `unit_tasting.py` использует встроенную библиотеку `unittest` для тестирования функций из `hashing.py`
Использование:

```bash
python unit_tasting.py -v
```

## Поиск коллизий

`collisions.py` содержит в себе 2 функции, занимающиеся подбором коллизий. Обе они работают для множества алгоритмов хеширования.

- `hash_brutforce` - перебирает последовательности из `N` байт
- `hash_brutforce_random` - подбирает генерируемые случайным образом последовательности из `digest_size` байт
