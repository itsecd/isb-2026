## Структура модулей

1. **`create.py`** — криптографическое ядро (генерация и проверка HMAC).
2. **`packet.py`** — упаковка данных и подписи в сетевой пакет.
3. **`atak.py`** — имитация перехвата/модификации данных и детектор взлома.
4. **`collision.py`** — перебор коллизий для усеченного хэша через `tqdm`.

## Интерфейсы и файлы

- **`main.py`** — консольная утилита с поддержкой флагов командной строки (`argparse`).
- **`gui.py`** — графический интерфейс на **PyQt5**. Реализован импорт текста из `.txt` и экспорт/импорт пакетов в `.json`.
- **`test_hmac.py`** — 10 автоматических юнит-тестов на базе модуля `unittest`.

## Быстрый запуск

```bash
pip install PyQt5 tqdm
python test_hmac.py
python gui.py
```
