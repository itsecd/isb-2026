## Лабораторная №4 "Хеш-функции"
### **Вариант: 5** (Поиск коллизий на укороченных хешах)

---

## 1. Цель работы
Исследовать вероятность возникновения коллизий и изучить атаку «парадокс дней рождения».

## 2. Функционал
- Исходные данные хешируются SHA-256, после результат отсекается побитовой маской для получения младших бит (8, 12, 16 бит).
- Интерфейс:
  - консоль (argparse с tqdm)
  - GUI (PyQt6)
- Тестирование (модуль tests.py)
- Исключения (два собственных класса ошибок для работы)

## 3. Математическое обоснование (Парадокс дней рождения)
Вероятность коллизии оценивается парадоксом дней рождения. Ожидаемое количество попыток $E$ для нахождения коллизии в пространстве из $N$ вариантов (где $N = 2^b$) рассчитывается по формуле:
$$E \approx 1.25 \cdot \sqrt{2^b}$$

## 4. Запуск приложения через консоль

Пример: `python main.py -stat -b 16 -e 200 -o 1.json`

- `-find` - Поиск одной коллизии.
- `-stat` - Серия экспериментов для сбора статистики.
- 
- `-b` - Разрядность усеченного хеша (8, 12, 16).
- `-e` - Количество экспериментов для запуска статистики.
- `-o` - Путь для экспорта результатов в формате JSON.

## 5. Запуск Юнит-тестирования

`python -m unittest -v tests.py`
