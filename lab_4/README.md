# Отчёт по лабораторной работе №4
## Проверка целостности файлов с использованием хеш-функций

---

### Архитектура и модульная структура приложения

* `main.py` — Анализирует вектор аргументов запуска (`sys.argv`). При наличии флагов делегирует управление в `cli.py`, при отсутствии — инициализирует графическую оболочку `gui.py`.
* `hasher.py` — Содержит автономные функции для потокового чтения файлов, расчёта контрольных сумм алгоритмом SHA-256 и симуляции криптоанализа.
* `cli.py` — Модуль парсинга командной строки на базе стандартной библиотеки `argparse`.
* `gui.py` — Графический интерфейс на базе фреймворка `PyQt6`.
* `test.py` — Модуль автоматизированного тестирования (`unittest`).

---


### Сводная таблица функций и потенциальных исключений:

| Название функции | Назначение | Входные параметры | Возвращаемое значение |
| --- | --- | --- | --- | --- |
| `calculate_file_hash` | Поблочное вычисление SHA-256 | `file_path: str`, `block_size: int` | `str` (hex-строка) | 
| `save_hash_to_file` | Экспорт контрольной суммы | `hash_value: str`, `output_path: str` | `None` | 
| `load_hash_from_file` | Импорт эталонного хеша | `hash_path: str` | `str` | 
| `verify_file_integrity` | Сравнение текущего и сохраненного хеша | `file_path: str`, `hash_path: str` | `Tuple[bool, str, str]` | 
| `simulate_collision_search` | Генерация частичной коллизии | `target_prefix_len: int` | `Tuple[str, str, int]` |
