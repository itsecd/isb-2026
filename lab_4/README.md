# Лабораторная работа №4

## Описание проекта

В рамках лабораторной работы была разработана программная система для проверки целостности и подлинности сообщений с использованием алгоритма HMAC-SHA256. Основной задачей проекта является реализация механизма, позволяющего вычислять криптографический код аутентификации сообщения и выполнять его последующую проверку при помощи секретного ключа.

Алгоритм HMAC используется для защиты информации от подмены и несанкционированного изменения. В ходе выполнения работы была изучена структура работы SHA-256 и механизм формирования HMAC на основе криптографической хеш-функции. Разработанная программа демонстрирует, как изменение даже одного символа исходного сообщения приводит к полному изменению итогового хеша, что позволяет эффективно выявлять любые модификации данных.

## Функциональные возможности программы

Приложение поддерживает два основных режима работы:

- вычисление HMAC для введённого сообщения;
- проверка корректности и подлинности HMAC.

Пользователь может ввести текст сообщения и секретный ключ, после чего программа вычисляет HMAC-SHA256 и выводит результат. Также реализована возможность проверки ранее полученного HMAC для подтверждения целостности данных.

В проекте дополнительно реализованы:

- обработка ошибок при некорректном вводе параметров;
- демонстрация лавинного эффекта SHA-256;
- unit-тесты для проверки корректности основных функций;
- графический интерфейс пользователя;
- консольный режим работы программы.

## Структура проекта

Проект состоит из нескольких модулей, каждый из которых отвечает за отдельную часть функциональности:

- `crypto_engine.py` — реализация вычисления и проверки HMAC;
- `gui_pyqt.py` — графический интерфейс приложения на PyQt6;
- `cli_interface.py` — консольный интерфейс;
- `collision_demo.py` — демонстрация изменения хеша при изменении входных данных;
- `tests.py` — unit-тесты;
- `settings.py` — хранение настроек и параметров приложения;
- `app.py` — основной файл запуска программы.

- argparse.

## Принцип работы программы

При запуске программы пользователь может выбрать режим вычисления или проверки HMAC. Для формирования криптографического кода используется секретный ключ и введённое сообщение. Далее выполняется вычисление HMAC с использованием алгоритма SHA-256.

При проверке программа повторно вычисляет HMAC для введённого сообщения и сравнивает его с исходным значением. Если значения совпадают, сообщение считается подлинным и неизменённым. В случае несовпадения выводится уведомление о возможной подмене данных.

Для демонстрации свойств криптографических хеш-функций была реализована отдельная функция, показывающая лавинный эффект. Даже минимальное изменение исходного текста приводит к значительному изменению итогового хеша.

## Тестирование

Для проверки корректности работы программы были реализованы unit-тесты. Тестирование позволяет убедиться в правильности вычисления HMAC, корректной работе проверки подлинности и обработке ошибок. Также были протестированы различные варианты входных данных и сценарии работы программы.

## Результат работы

В результате выполнения лабораторной работы была разработана система проверки подлинности сообщений на основе алгоритма HMAC-SHA256. Реализованное приложение позволяет вычислять и проверять HMAC, обеспечивая контроль целостности передаваемых данных и защиту от их изменения. Полученные результаты подтверждают эффективность использования криптографических механизмов для обеспечения безопасности информации.
