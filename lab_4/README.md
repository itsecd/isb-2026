---

## 2. Краткие теоретические сведения

HMAC — это код аутентификации сообщения, основанный на хеш-функции и секретном ключе.

В отличие от обычного хеша, HMAC зависит не только от сообщения, но и от секретного ключа:

```text
HMAC = HMAC(message, secret_key)
```

В данной работе используется алгоритм **HMAC-SHA256**.

HMAC позволяет:

- проверять целостность данных;
- подтверждать подлинность сообщения;
- обнаруживать изменение сообщения;
- защищать данные от простой подмены.

---

## 3. Как работает алгоритм

Алгоритм работы программы:

1. Пользователь вводит сообщение и секретный ключ.
2. Программа вычисляет HMAC-SHA256.
3. Сообщение передается вместе с HMAC.
4. Для проверки программа повторно вычисляет HMAC по сообщению и ключу.
5. Если вычисленный HMAC совпадает с полученным, сообщение считается корректным.
6. Если HMAC отличается, значит сообщение, ключ или код аутентификации были изменены.

---

## 4. Свойства HMAC-SHA256

HMAC-SHA256 обладает следующими свойствами:

- зависит от секретного ключа;
- изменяется при любом изменении сообщения;
- позволяет обнаружить подмену данных;
- подтверждает подлинность сообщения;
- использует криптографическую хеш-функцию SHA-256.

## 6. Запуск программы

Установка зависимостей:

Создание HMAC:

```bash
python main.py generate --message "Hello" --key "secret"
```

Проверка HMAC:

```bash
python main.py verify --message "Hello" --key "secret" --hmac "<HMAC>"
```

Запуск графического интерфейса:

```bash
python gui.py
```
