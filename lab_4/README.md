# Лабораторная работа №4

> **Вариант 2** · Исследование лавинного эффекта хеш-функций

---

## Описание

Программа исследует **лавинный эффект** криптографических хеш-функций:
при минимальном изменении входных данных (один символ, один бит, смена регистра)
вычисляется, насколько изменился хеш — в битах и процентах.

Поддерживаемые алгоритмы: `SHA-256`, `SHA-1`, `MD5`, `SHA3-256`.

---

## Ход выполнения работы

**1. Изучение SHA-256 и лавинного эффекта**

Изучил принцип работы SHA-256: алгоритм преобразует входные данные
в 256-битный хеш через 64 раунда нелинейных операций. Ключевое свойство —
лавинный эффект: изменение одного бита входа меняет ~50% бит выхода.

**2. Реализация ядра вычислений (hash_core.py)**

Реализовал базовые функции: вычисление хеша через `hashlib`,
перевод hex-дайджеста в биты, подсчёт расстояния Хэмминга.
Добавил три типа модификаций входных данных:
замену символа, инверсию бита через XOR и смену регистра буквы.

**3. Проведение экспериментов**

Запустил серию из 30 экспериментов (10 × 3 типа модификаций) для строки `"hello world"`.
Для каждого эксперимента фиксировал исходный и изменённый хеш,
количество и процент различающихся бит.

**4. Анализ результатов**

| Алгоритм | Среднее % различий | Оценка |
|---|---|---|
| SHA-256 | ~50% | Отличный |
| SHA-1 | ~50% | Хороший |
| MD5 | ~50% | Хороший |
| SHA3-256 | ~50% | Отличный |

Все алгоритмы показали ~50% изменённых бит, что подтверждает
наличие качественного лавинного эффекта. Тип модификации
(символ / бит / регистр) не влияет на среднее значение.

**5. Реализация интерфейсов**

Разработан CLI-интерфейс с `argparse` и прогресс-баром `tqdm`,
а также графический интерфейс на `PyQt6` с таблицей результатов
и фоновым потоком для вычислений.

**6. Тестирование**

Написано 46 юнит-тестов через `pytest`, покрывающих все функции модуля.
Все тесты проходят успешно.

## Ответы на контрольные вопросы

**1. Что такое лавинный эффект?**
Свойство алгоритма: изменение одного бита входа изменяет ~50% бит выхода.

**2. Почему лавинный эффект важен?**
Обеспечивает непредсказуемость — злоумышленник не может угадать вход
по незначительным изменениям хеша.

**3. Какие хеш-функции обладают хорошим лавинным эффектом?**
SHA-256, SHA-3, SHA-1. MD5 тоже обладает, но уязвим к коллизиям.

**4. Как оценить качество хеш-функции?**
Серия экспериментов: среднее ~50% изменённых бит при случайных малых
изменениях входа — признак качественной функции.

**5. Что происходит при изменении одного бита входных данных?**
Меняется в среднем половина бит хеша. Зависимость нелинейная:
нельзя предсказать, какие именно биты изменятся.
