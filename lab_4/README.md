# Лабораторная работа 4 вар 3 хэширование паролей и защита учётных данных
Работа выполнена: студент 6214-100503D Сутягин А.В
## Функционал программы
- Регистрация и авторизация пользователей
- Использование алгоритмов шифрования: SHA-256 без соли, SHA-256 с солью, bcrypt
- Проверка на уязвимости алгоритмов SHA-256 без соли и SHA-256 с солью
- Поддержка GUI и CLI интерфейсов
- Выполнение Юнит-тестов

## Архитектура
- main.py - основная точка входа в приложение
- gui.py - графический интерфейс на базе PyQt5
- cli.py - консольный интерфейс, на базе парсинга аргументов с использованием argparse
- UserStorage.py - модуль для работы с сохранением и чтением записей в JSON хранилище
- UserManager.py - модуль, отвечающий за работу с пользователями - Регистрация, Авторизация
- hasher.py - модуль, отвечающий за хэширование паролей, использует SHA-256, SHA-256 с солью, bcrypt
- analysator.py - модуль, отвечающий за проверку алгоритмов SHA-256 без с соли и SHA-256 с солью на брутфорс
- unit_tests.py - набор юнит-тестов, для проверки работоспособности функционала программы

### Программа отвечает требованиям:
- Сохранение логина и пароля
- Генерация случайной соли
- Вычисление хэша пароля
- Проверяет корректность пароля
- Использует SHA-256 и bcrypt 

##  Запуск программы

1. Склонируйте репозиторий в рабочую папку
2. Установите зависимости
```bash
pip install -r requirements.py
```
3. Запустите приложение:
- Для запуска GUI:
```bash
python main.py
```
- для запуска CLI версии:
*Пример регистрации нового юзера*
```bash 
python main.py -u <логин> -p <пароль>
```
*Запуск проверки на брутфорс:*
```bash
python main.py crack
```
*Запуск Юнит-тестов:*
```bash
python unit_tests.py
```
