# Отчёт по лабораторной работе: Хеш функции

# Вариант 1

## 1. Цель работы
Написать приложение для проверки целостности файлов с использованием хеш-функции SHA-256.
Функционал: сохранение хешей, верификация файлов, поиск коллизий.

## 2. Описание программы
Программа состоит из `6` модулей.

### 2.1. main.py

Вход в приложение. Его задача — проанализировать аргументы командной строки при запуске. Если пользователь передал параметры, модуль делегирует управление консольному интерфейсу, а если аргументов нет — инициирует запуск графического приложения.

### 2.2. crypto.py

В этом модуле реализованы функции вычисления SHA-256 хеша, сверки текущего хеша файла с эталонным, а также поиск коллизий.

### 2.3. read_write_file.py

Вспомогательный модуль, который отвечает за чтение и запись хеш в файлы. Нужен чтобы не дублировать логику открытия/закрытия файлов.

### 2.4. cli.py

Модуль, обеспечивающий взаимодействие с пользователем через командную строку. Он использует стандартную библиотеку argparse для парсинга введенных команд.


### 2.5. gui.py

Модуль графического интерфейса, реализованного с помощью `PyQt5`. Он предоставляет пользователю полноценное окно с кнопками и полями вывода.

### 2.6. test.py

Модуль автоматизированного тестирования. Он содержит набор `unit-тестов`, которые проверяют корректность работы всех функций (хеширование, поиск коллизий, обработка ошибок при отсутствии файлов).


## 3. Вывод

В ходе лабораторной работы была успешно реализована система контроля целостности файлов. Разделение программы на независимые модули позволило логично организовать структуру проекта: от низкоуровневых операций с файлами до высокоуровневого графического интерфейса. Использование автоматизированного тестирования подтвердило корректность работы реализованных алгоритмов.
