# Лабораторная работа № 3 "Построение гибридной криптосистемы"

Консольное приложение на Python, реализующее гибридную криптосистему на основе алгоритмов RSA и IDEA.

RSA используется для шифрования симметричного IDEA-ключа, а IDEA в режиме CBC применяется для шифрования содержимого файлов.

---

## Структура проекта

`main.py` — точка входа в программу. Обрабатывает аргументы командной строки, загружает настройки и запускает нужный режим работы (генерация ключей, шифрование или дешифрование)

`settings_loader.py` — отвечает за загрузку и проверку конфигурации из файла settings.json

`hybrid.py` — реализует основную логику гибридной криптосистемы, связывает между собой симметричное и асимметричное шифрование, файловые операции

`symmetric.py` — содержит функции для работы с симметричным алгоритмом IDEA: генерацию ключа, шифрование и дешифрование данных

`asymmetric.py` — содержит функции для работы с RSA: генерацию пары ключей, их сериализацию/десериализацию, а также шифрование и расшифрование симметрического ключа

`file_utils.py` — содержит вспомогательные функции для чтения и записи файлов

`settings.json` — файл конфигурации, в котором хранятся пути к входным данным, выходным файлам и ключам

`requirements.txt` — список зависимостей проекта, необходимых для его запуска

`data` — каталог с исходным текстом, зашифрованными данными и результатом дешифрования

`keys` — каталог для хранения RSA-ключей и зашифрованного симметрического ключа

---

## Используемые алгоритмы

- RSA-2048
- IDEA-128
- CBC mode
- OAEP padding
