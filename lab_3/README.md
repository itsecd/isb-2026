# Лабораторная работа № 3 "Построение гибридной криптосистемы"

Консольное приложение на Python, реализующее гибридную криптосистему на основе алгоритмов RSA и IDEA.

RSA используется для шифрования симметричного IDEA-ключа, а IDEA в режиме CBC применяется для шифрования содержимого файлов.

---

## Структура проекта

 `main.py` - Обрабатывает аргументы командной строки и запускает нужный режим: генерация ключей; шифрование;дешифрование.
 
 `cipher_core.py` - Содержит основную криптографическую логику:генерация IDEA ключа; генерация RSA ключей; RSA-OAEP шифрование; IDEA-CBC шифрование; padding данных.

 `settings_loader.py` - Загрузка настроек из файла settings.json и обработка ошибок.

 `settings.json` - Файл конфигурации с путями к файлам и ключам.

 `requirements.txt` - Список используемых библиотек.

---

## Используемые алгоритмы

- RSA-2048
- IDEA-128
- CBC mode
- OAEP padding
