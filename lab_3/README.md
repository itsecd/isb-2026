# Описание работы Hybrid Crypto Tool

Приложение реализует гибридную схему шифрования, основанную на сочетании асимметричного алгоритма **RSA** и симметричного алгоритма **ChaCha20**. Работа разделена на три основных этапа:

1.  **Генерация ключей**: После нажатия на кнопку **Создать ключи** создаются ключи RSA (публичный и приватный), симметричный ключ ChaCha20 и файл с одноразовым кодом (nonce) (для проверки ключи сохраняются в `public.pem`, `private.pem`, `symmetric_key.txt` и `nonce.bin` соответственно через вспомогательный модуль `functions.py`).
2.  **Шифрование**: После выбора режима **Шифрование** и нажатия на кнопку **Выполнить** происходит шифрование текста симметричным ключом и сохранение в `enc_file.txt`. Сам симметричный ключ шифруется публичным ключом RSA и сохраняется отдельный файл `enc_sym_key.bin`.
3.  **Дешифрование**: После выбора режима **Дешифрование** и нажатия на кнопку **Выполнить** происходит дешифрование зашифрованного симметричного ключа приватным ключом RSA. С помощью него текст дешифруется и сохраняется в `dec_file.txt`

Управление путями к файлам осуществляется через `settings.json`, через `crypto_service.py` задействуются модули `RSA.py`,`ChaCha20.py` и `functions.py`, а взаимодействие пользователя с системой происходит в интерфейсе `application.py`.
