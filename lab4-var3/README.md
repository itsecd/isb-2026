# Лабораторная работа №4  
## Основы информационной безопасности  
### Тема: Хеш-функции  
### Вариант 3 — Хеширование паролей и защита учетных данных

---

## Цель работы

Изучить методы безопасного хранения паролей и реализовать систему аутентификации пользователей с использованием криптографических хеш-функций и соли.

---

## Теоретическая часть

Хранение паролей в открытом виде недопустимо, так как при утечке базы данных злоумышленник получает полный доступ к учетным записям пользователей.

Для защиты применяются:

- криптографические хеш-функции (SHA-256);
- соль (salt);
- адаптивные алгоритмы хеширования (bcrypt).

---

## Реализованный функционал

В рамках работы разработана система аутентификации, которая включает:

- регистрацию пользователей;
- авторизацию пользователей;
- хранение логинов в SQLite базе данных;
- два режима хранения паролей:
  - небезопасный (SHA-256 без соли);
  - безопасный (bcrypt + соль);
- генерацию случайной соли;
- проверку корректности пароля;
- графический интерфейс (PyQt5);
- работу через командную строку (argparse);
- демонстрацию brute-force атаки;
- модульные тесты (unittest);
- визуализацию перебора (tqdm).

---

## Структура базы данных

Таблица `users` содержит:

- `id` — идентификатор пользователя;
- `username` — логин;
- `password_hash` — хеш пароля;
- `salt` — соль (для безопасного режима);
- `is_safe` — флаг режима хранения.

---

## Описание режимов хранения паролей

### Небезопасный режим (SHA-256)

- пароль хешируется без соли;
- одинаковые пароли дают одинаковый хеш;
- уязвим к rainbow table и словарным атакам;
- используется только для демонстрации уязвимости.

---

### Безопасный режим (bcrypt)

- используется адаптивный алгоритм bcrypt;
- применяется соль;
- устойчив к brute-force атакам;
- рекомендуется для реальных систем.

---

## Демонстрация атаки brute-force

В лабораторной работе реализована демонстрация перебора пароля для небезопасного режима.

Используется:

- последовательный перебор кандидатов;
- визуализация процесса через tqdm;
- сравнение хешей.

---

## Тестирование

Проект покрыт модульными тестами (`unittest`), которые проверяют:

- регистрацию пользователей (safe/unsafe);
- корректную авторизацию;
- обработку неверных паролей;
- работу с несуществующими пользователями;
- различие хешей в безопасном и небезопасном режимах;
- структуру базы данных;
- работу brute-force механизма.

---

## Интерфейс пользователя

Реализован графический интерфейс на PyQt5:

- регистрация пользователя;
- ввод логина и пароля;
- переключение режима безопасности;
- вывод сообщений об успехе или ошибке.
