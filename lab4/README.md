## Тесты

### test_hashing.py

**test_default_length** — генерация соли длиной 16 байт по умолчанию.  
**test_custom_length** — генерация соли произвольной длины.  
**test_randomness** — две соли не совпадают.  
**test_hash_with_salt_returns_string** — хеш SHA-256 возвращается строкой из 64 символов.  
**test_hash_without_salt_returns_string** — хеш без соли тоже строка правильной длины.  
**test_same_password_same_hash** — одинаковый пароль и соль дают одинаковый хеш.  
**test_different_salt_different_hash** — разная соль даёт разный хеш для одного пароля.  
**test_different_password_different_hash** — разные пароли с одной солью дают разные хеши.  
**test_verify_correct_password** — проверка верного пароля возвращает True.  
**test_verify_incorrect_password** — проверка неверного пароля возвращает False.  
**test_bcrypt_hash_returns_string** — bcrypt возвращает строку.  
**test_bcrypt_same_password_different_hash** — bcrypt каждый раз даёт разный хеш (встроенная соль).  
**test_bcrypt_verify_correct** — проверка верного пароля bcrypt.  
**test_bcrypt_verify_incorrect** — проверка неверного пароля bcrypt.  
**test_avalanche_sha256** — изменение одного символа меняет 30-70% бит хеша.  
**test_find_collision_2_bytes** — коллизия для 2 байт находится.  
**test_find_collision_returns_dict** — результат содержит все нужные поля.

### test_auth.py

**test_register_new_user_sha256** — регистрация с SHA-256.  
**test_register_new_user_bcrypt** — регистрация с bcrypt.  
**test_register_duplicate_user** — повторная регистрация отклоняется.  
**test_register_empty_password_raises** — пустой пароль вызывает ValueError.  
**test_authenticate_valid_sha256** — вход с правильным паролем SHA-256.  
**test_authenticate_invalid_password** — вход с неверным паролем отклоняется.  
**test_authenticate_nonexistent_user** — вход несуществующего пользователя.  
**test_authenticate_valid_bcrypt** — вход с правильным паролем bcrypt.  
**test_list_users** — получение списка пользователей.  
**test_user_data_persists** — данные сохраняются между вызовами.

## Инструкция по запуску

### Установка зависимостей

pip install -r requirements.txt

### Режимы работы

**Графический интерфейс:**

python main.py gui

**Регистрация через консоль:**

python main.py register --username user --password pass
python main.py register --username user --password pass --algorithm bcrypt

**Вход через консоль:**

python main.py login --username user --password pass

**Демонстрация лавинного эффекта:**

python main.py avalanche

**Поиск коллизии:**

python main.py collision --bytes 2

**Запуск юнит-тестов:**

python main.py test

## Вывод

В ходе выполнения лабораторной работы была реализована система аутентификации пользователей с безопасным хранением паролей. Программа поддерживает два алгоритма хеширования: SHA-256 с солью и bcrypt со встроенной солью и адаптивной стоимостью.

Проведено сравнение подходов к хранению паролей (без соли, с солью, специализированные алгоритмы). Реализована демонстрация лавинного эффекта хеш-функции SHA-256, подтверждающая что минимальное изменение входных данных приводит к кардинальному изменению хеша (около 50% бит).

Реализован поиск коллизий для усечённого хеша методом полного перебора с визуализацией процесса через tqdm. Практически подтверждено что для 2 байт усечённого хеша коллизия находится быстро, но с ростом разрядности сложность экспоненциально возрастает.

Графический интерфейс на PyQt5 обеспечивает удобное взаимодействие с программой, а юнит-тесты подтверждают корректность всех критических компонентов системы.
