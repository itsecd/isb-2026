# Отчёт по лабораторной работе №4 (вариант №1)

## Что требовалось?
Было необходимо реализовать механизм проверки целостности файлов с использованием хеш-функций.

<br>

## Файлы и за что они отвечают
### ▷ `work_with_hash.py`
Этот файл отвечает за всю работу с хешем: его вычисление, запись в файл, чтение оттуда, очистка файла с хешем.

Там же реализована функция проверки целостности файла, которая работает с помощью сравнения хеша, записанного в файл, и хеша, вычисленного только что. 

В этом же файле реализуется функция поиска частичной коллизии: для хеша выбранного файла подбирается строка, у которой первые несколько символов хеша (от 1 до 5, в зависимости от выбора пользователя) будут совпадать с тем же количеством символов у хеша выбранного файла.

### ▷ `unit_tests.py`
В этом файле реализованы unit-тесты, которые проверяют корректность работы реализованных функций.

### ▷ `command_line_interface.py`
Этот файл отвечает за работу приложения в консольном режиме. 

С помощью библиотеки `argparse` реализован разбор аргументов командной строки. Пользователь может выбрать один из взаимоисключающих режимов работы (сохранение хеша, проверка целостности, поиск коллизии, удаление файла).

### ▷ `graphical_interface.py`
Этот файл реализует графический интерфейс пользователя на базе библиотеки `PyQt6`.

### ▷ `main.py`
Главная точка входа в приложение, объединяющая консольный и графический интерфейсы. 

Файл анализирует параметры запуска: если пользователь передал аргументы командной строки, управление автоматически передается модулю `command_line_interface.py`, а если запуск произведен без флагов - открывается графическое окно из `graphical_interface.py`.

### ▷ `text.txt`
Этот файл содержит в себе текст. Нужен для демонстрации работы программы.

### ▷ `calculated_hash.txt`
Это файл, куда сохраняется хеш выбранного файла. В данном случае файла `text.txt`.

<br>
