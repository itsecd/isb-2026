# Лабораторная работа №4. Хеширование паролей и защита учетных данных

**Вариант 3.** Хеширование паролей и защита учетных данных.

## Цель работы
Изучить методы безопасного хранения паролей и реализовать систему аутентификации
пользователей с использованием криптографических хеш-функций и соли.

## Краткие теоретические сведения
Пароли не должны храниться в открытом виде. Для защиты используются:
- криптографические хеш-функции (SHA-256);
- соль (Salt) — случайная строка, добавляемая к паролю перед хешированием;
- специальные алгоритмы: bcrypt, scrypt, Argon2.

### Почему нельзя хранить пароли в открытом виде
При утечке базы данных злоумышленник сразу получает доступ ко всем учётным записям.

### Что такое соль
Соль — это случайная строка, уникальная для каждого пользователя.
Она добавляется к паролю перед хешированием, чтобы одинаковые пароли
давали разные хеши, и чтобы исключить атаки по rainbow tables.

### Что такое rainbow tables
Rainbow tables — это заранее вычисленные таблицы соответствия хешей и паролей.
Если пароль хеширован без соли, злоумышленник может найти его в таблице за секунды.
Соль делает такие таблицы бесполезными.

### Почему SHA-256 недостаточно для хранения паролей
SHA-256 — быстрая хеш-функция. Злоумышленник может перебирать миллиарды паролей
в секунду на GPU. Для хранения паролей рекомендуются медленные алгоритмы:
bcrypt, scrypt, Argon2.

## Описание программы
Программа реализует систему регистрации и авторизации пользователей
с двумя режимами хранения паролей:
- **Безопасный режим (с солью):** к паролю добавляется случайная соль,
  вычисляется SHA-256 хеш, в базе хранятся хеш и соль.
- **Небезопасный режим (без соли):** пароль хешируется без соли,
  в базе хранится только хеш.

### Функциональность
- Регистрация нового пользователя
- Авторизация существующего пользователя
- Выбор режима хранения (с солью / без соли)
- Демонстрация уязвимости небезопасного режима

### Интерфейсы
- **GUI** на PyQt5 с полями ввода, выбором режима и логом работы
- **CLI** через argparse с параметрами командной строки
