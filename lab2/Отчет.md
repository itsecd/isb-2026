В ходе лабораторной работы были реализованы генераторы псевдослучайных бинарных последовательностей на языках C++, Java и Python. 
С помощью каждого генератора была получена бинарная последовательность длиной 128 бит и сохранена в файл.

Для анализа полученных данных была разработана программа на языке Python, реализующая три теста NIST. Для каждой последовательности были рассчитаны значения p-value.

Вывод: В результате выполнения лабораторной работы были сгенерированы и проанализированы псевдослучайные последовательности. По результатам проведённого тестирования 
все три генератора успешно прошли выбранные статистические тесты NIST. Наиболее стабильные результаты продемонстрировал генератор Python, показавший высокие значения 
p-value во всех тестах. Генераторы Java и C++ также показали удовлетворительные результаты, однако последовательность, полученная с помощью генератора C++, имела более 
низкое значение p-value в тесте на самую длинную последовательность единиц в блоке. Поскольку все полученные значения p-value оказались выше уровня значимости 0,01, 
можно сделать вывод, что сгенерированные последовательности обладают свойствами случайности и могут использоваться для дальнейшего статистического анализа.
