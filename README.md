# Лабораторная работа по Основам Информационной Безопасности №4 "Хеш-функции"
Вариант 5

## Цель работы
Исследовать вероятность возникновения коллизий и изучить атаку "парадокс дней рождения".

## Програмная реализация
Итоговая программа разделена на несколько модулей:
- "collision_unittests.py" -  модуль с покрывающими код юнит-тестами
- "hash.py" -  модуль с функциями для вычисления полного и укороченного хэша
- "collisions.py" -  модуль c функциями для проведения экспериментов по поиску коллизий укороченного хэша
- "gui.py" -  модуль с GUI
- "main.py" -  точка входа/главный файл, управляющий логикой работы программы

Для запуска программы в терминале нужно использовать флаг --cli, для GUI - --gui, а для запуска юнит-тестов - --uni.
