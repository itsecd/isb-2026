## Описание работы
Данная лабораторная работа представляет собой реализацию **гибридной криптосистемы**. Система сочетает в себе высокоскоростное симметричное шифрование и асимметричное шифрование для безопасной передачи ключей.

**Симметричный алгоритм:** AES.
**Асимметричный алгоритм:** RSA.

### Процесс отработки системы:
#### Шифрование:  
1.  **Симметричная часть:** Данные шифруются алгоритмом **AES** в режиме **CBC** с использованием случайного вектора инициализации (IV).
2.  **Асимметричная часть:** Сессионный ключ AES шифруется открытым ключом **RSA** с использованием схемы **OAEP**, что позволяет безопасно хранить или передавать его.
#### Дешифрование:
1. **Асимметричная часть:** Зашифрованный сессионный ключ AES считывается из файла. С помощью закрытого ключа RSA и схемы OAEP происходит его дешифрование для получения исходного симметричного ключа.
2. **Симметричная часть:** Из начала зашифрованного файла (`encrypted.bin`) извлекаются первые 16 байт вектора инициализации (IV), который был сгенерирован при шифровании.
Оставшаяся часть файла расшифровывается алгоритмом AES в режиме CBC с использованием полученного ключа и IV.
3. **Unpadding:** После дешифрования данные проходят через процедуру PKCS7 unpadding, которая удаляет байты, добавленные для выравнивания блока. В результате получается исходный текстовый файл

## Структура

* `app.py` — Графический интерфейс на базе PyQt5.
* `keygen.py` — Генерация ключей RSA и сессионного ключа AES.
* `encrypt.py` — Логика шифрования данных.
* `decrypt.py` — Логика дешифрования данных.
* `settings_loader.py` — Модуль для управления файлом настроек (`settings.json`).
* `settings.json` — Файл настроек.

## Запуск и использование

### 1. Предварительные требования
Установите зависимости, перечисленные в `requirements.txt`:
```bash
pip install -r requirements.txt  
```
### 2. Запуск
```python
python app.py
```
