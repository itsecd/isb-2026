### Краткие теоретические сведения

HMAC (Hash-based Message Authentication Code) — механизм аутентификации сообщений, основанный на использовании [хеш-функции](https://habr.com/ru/post/534596/) и секретного ключа.

HMAC обеспечивает:
- контроль целостности;
- подтверждение подлинности сообщения.

---

### Задание

1. Формирование HMAC для сообщения.
2. Передачу сообщения и HMAC.
3. Проверку корректности HMAC.
4. Обнаружение изменения данных.

### Требования к программе

Программа должна:
- использовать HMAC-SHA256;
- поддерживать ввод секретного ключа;
- проверять подлинность сообщения;
- обнаруживать изменение данных.

В файле load_and_save.py находится логика сохранения/считывания данных из файлов

В файле send_and_receive.py происходит создание сообщения из данных и hmac подписи
Сохранение и считывание этого сообщения из файлов, а так-же проверка целостности полученного сообщения.

В файле hmac_logic.py находится логика создания и проверки hmac подписи
