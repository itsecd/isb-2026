## Хеширование паролей и защита учетных данных

В работе реализовано два способа хранения паролей в базе данных:

# Сравнение результатов: хранение с солью и без соли
|   Характеристика   | Без соли (SHA-256)  | С солью (bcrypt) |
|--------------------|---------------------|------------------|
| Одинаковые пароли  | Дают одинаковый хеш | Дают разные хеши |
| Радужные таблицы   |       Уязвим        |     Устойчив     |

# Архитектура проекта
database.py - работа с SQLite
hash.py - хеширование bcrypt (с солью)
without_salt.py - хеширование SHA-256 (без соли)
mainwindow.py - точка входа 
stylehelper.py - применение стилей
untit_tests.py - тесты

Запуск программы осуществляется при помощи команды py mainwindow.py --path_db (аргумент) --salt_mode (аргумент)
или командой py mainwindow.py. При применении первой команды пользователь сам будет выбирать путь к базе данных и способ хранения паролей(с солью или без)

Запуск тестов осуществляется командой pytest unit_tests.py
