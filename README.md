# Вариант 1

## 1. Цель работы

Изучить принципы работы криптографических хеш-функций и реализовать механизм проверки целостности файлов.

## 2. Описание программы

Программна спроектирован по модульному принципу и состоит из `6` взаимосвязанных файлов.

### 2.1. main.py

Точка входа для запуска приложения в графическом режиме. Модуль отвечает за инициализацию контекста Qt, создание экземпляра главного окна и запуск основного цикла обработки событий графической оболочки.

### 2.2. hash.py

Содержит ключевые вычислительные функции:

- `calculating_hash`: выполняет поблочное чтение и расчет хеша SHA-256
- `integrity_check`: осуществляет сверку текущего состояния файла с эталонным слепком.
- `collision_demo`: реализует алгоритм перебора числовых строк для нахождения совпадений усеченных префиксов хешей заданной сложности

### 2.3. load_and_save_hash.py

Модуль реализует запись результатов хеширования (в формате `хэш  имя_файла`) , а также парсинг файлов контрольных сумм.

### 2.4. cli.py

Интерфейс командной строки , функционирующий независимо от графической системы. Использует модуль `argparse` для разбора системных флагов (`--file`, `--check`, `--collision`). Для визуализации подбора коллизий в режиме реального времени интегрирована библиотека `tqdm`, обеспечивающая динамический вывод прогресс-бара непосредственно в консоль.

### 2.5. py_qt.py

Модуль графического интерфейса пользователя (GUI).

### 2.6. unit_test.py

Модуль автоматизированного тестирования на базе пакета `unittest`.

## 3. Вывод

В ходе выполнения лабораторной работы была спроектирована и успешно реализована система контроля целостности информации.
