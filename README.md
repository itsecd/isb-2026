## Описание

В системе продемонстрировано два подхода к хранению паролей в базе данных:

| Подход | Метод | Уязвимость |
|--------|-------|------------|
|  Небезопасный | HEX-кодирование без соли | Брутфорс, радужные таблицы |
|  Безопасный | bcrypt + случайная соль | Устойчив к атакам |

Приложение включает графический интерфейс на PyQt5 и CLI-режим для демонстрации атаки брутфорсом на незащищённый хэш.

## Архитектура

```
┌─────────────┐       ┌─────────────┐       ┌─────────────┐
│   main.py   │─────▶ │  backend.py │─────▶│    DB.py    │
│  (Точка     │       │   (Auth)    │       │ (Database)  │
│   входа)    │       │             │       │             │
└─────────────┘       └─────────────┘       └──────┬──────┘
       │                                           │
       ▼                                           ▼
┌─────────────┐                          ┌─────────────────┐
│    app.py   │                          │  database.db    │
│  (PyQt5 GUI)│                          │  (SQLite)       │
└─────────────┘                          └─────────────────┘
```

- **`main.py`** — точка входа, разбор аргументов CLI
- **`app.py`** — графический интерфейс (PyQt5)
- **`backend.py`** — основная логика программы: регистрация, верификация, брутфорс
- **`DB.py`** — слой доступа к данным (SQLite)

## Запуск

### Графический интерфейс (по умолчанию)

```bash
#GUI режим:
python main.py
# или явно:
python main.py --mode gui
```

### CLI-демонстрация брутфорса

```bash
# Демо с паролем по умолчанию "123"
python main.py --mode cli-demo

# Демо с произвольным паролем
python main.py --mode cli-demo --demo-pass ваш_пароль
```

Режим `cli-demo` регистрирует пользователя **без соли**, перехватывает хэш и запускает брутфорс-атаку, наглядно демонстрируя уязвимость незащищённого хранения.

## Конфигурация

Файл `settings.json`:

```json
{
  "db_path": "database.db",
  "use_salt": true,
  "salt_length": 16,
  "bruteforce_iters": 2000,
  "bcrypt_rounds": 12
}
```

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| `db_path` | `database.db` | Путь к файлу базы данных SQLite |
| `use_salt` | `true` | Режим использования соли по умолчанию в GUI |
| `salt_length` | `16` | Длина генерируемой соли (байт) |
| `bruteforce_iters` | `2000` | Кол-во итераций брутфорса |
| `bcrypt_rounds` | `12` | Количество раундов хеширования bcrypt |

При отсутствии или повреждении файла настройки применяются автоматически.

## Cравнение подходов

### Небезопасный режим (`unsafe_registration`)

```
password → encode('utf-8') → .hex() → сохранить в БД
```

- Детерминированный: один и тот же пароль = один и тот же хэш
- Легко взламывается брутфорсом или по радужным таблицам

### Безопасный режим (`safe_registration`)

```
password + random_salt → bcrypt(rounds=12) → сохранить хэш и соль в БД
```

- Уникальная соль для каждого пользователя
- Количество раундов bcrypt замедляет перебор
- Устойчив к радужным таблицам и массовому брутфорсу
