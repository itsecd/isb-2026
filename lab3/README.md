# Гибридная система шифрования файлов (CAST5 + RSA)

## Описание

Проект реализует гибридную систему шифрования файлов с использованием:

- **CAST5** — для симметричного шифрования данных;
- **RSA** — для защиты симметричного ключа.

Программа позволяет:

- генерировать ключи;
- шифровать файлы;
- расшифровывать файлы.

---

## Описание файлов

### `crypto_utils.py`

Файл содержит криптографические функции:

- генерация ключа **CAST5**;
- шифрование и дешифрование файлов (**CAST5 + CBC + PKCS7**);
- генерация RSA-ключей (2048 бит);
- сохранение и загрузка RSA-ключей;
- шифрование и расшифрование симметричного ключа через **RSA OAEP + SHA-256**.

**Результат работы:**  
создание ключей и выполнение операций шифрования/дешифрования.

---

### `main.py`

Основной исполняемый файл проекта.

Поддерживает три режима работы:

#### Генерация ключей

```bash
python main.py -gen
```

Создаются:

- `public.pem`
- `private.pem`
- `symmetric_key.bin`

#### Шифрование файла

```bash
python main.py -enc
```

Результат:

```text
data/encrypted.bin
```

#### Дешифрование файла

```bash
python main.py -dec
```

Результат:

```text
data/decrypted.txt
```

---

### `settings.json`

Конфигурационный файл проекта.

Содержит:

- пути к входному и выходным файлам;
- пути к RSA-ключам;
- путь к зашифрованному симметричному ключу;
- размер ключа CAST5.

Пример параметра:

```json
"cast5_key_size": 128
```

## Результат работы программы

После выполнения полного цикла файл `decrypted.txt` должен совпадать с исходным `input.txt`, что подтверждает корректную работу алгоритмов шифрования и дешифрования.
