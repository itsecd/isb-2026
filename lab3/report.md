## 1. Цель работы

Реализовать гибридную криптосистему, сочетающую преимущества симметричного и асимметричного шифрования:
- симметричный алгоритм **SM4** используется для шифрования данных (быстрый, эффективен на больших объёмах);
- асимметричный алгоритм **RSA** используется для безопасной передачи симметричного ключа (не требует секретного канала).

## 2. Используемые алгоритмы

### 2.1 SM4 (симметричный алгоритм)

SM4 — китайский блочный шифр, принятый как государственный стандарт КНР (GB/T 32907-2016) в 2006 году. Разработан Государственным управлением по криптографии Китая. Изначально применялся в стандарте беспроводных сетей WLAN (WAPI).

Характеристики:
- Длина блока: **128 бит**
- Длина ключа: **128 бит**
- Структура: сеть Фейстеля с 32 раундами
- Режим работы в данной реализации: **CBC** (Cipher Block Chaining) — каждый блок открытого текста побитово складывается по XOR с предыдущим блоком шифртекста перед шифрованием

Алгоритм считается криптостойким, известных практических атак на полный перебор ключа нет. Поддерживается библиотекой OpenSSL и рядом TLS-реализаций. Не является международным стандартом, в отличие от AES.

### 2.2 RSA (асимметричный алгоритм)

RSA — алгоритм асимметричного шифрования, разработанный в 1977 году Ривестом, Шамиром и Адлеманом. Основан на вычислительной сложности задачи факторизации больших чисел.

Характеристики в данной реализации:
- Размер ключа: **2048 бит**
- Схема паддинга: **OAEP** (Optimal Asymmetric Encryption Padding) с хэш-функцией **SHA-256**
- Публичный показатель: **65537**

OAEP усиливает классический RSA за счёт двух криптостойких хэш-функций и случайного паддинга, защищая от атак на основе подобранного шифртекста.

## 4. Описание модулей и функций

### 4.1 `file_utils.py` — утилиты

Вспомогательный модуль, используемый всеми остальными модулями.

| Функция | Описание |
|---|---|
| `log(msg)` | Выводит сообщение о ходе выполнения в формате `[*] msg` |

| `save_bytes(data, path)` | Сохраняет байтовые данные в файл; перед записью вызывает `_ensure_dir` для автоматического создания папок |
| `load_bytes(path)` | Читает и возвращает содержимое файла в виде байт |

### 4.2 `symmetric.py` — SM4-CBC

Модуль симметричного шифрования. Реализует генерацию ключа, шифрование и дешифрование данных алгоритмом SM4 в режиме CBC с паддингом PKCS7.

**Константы:**
- `BLOCK_SIZE_BITS = 128` — размер блока SM4 в битах
- `KEY_SIZE_BYTES = 16` — размер ключа (128 бит = 16 байт)
- `IV_SIZE_BYTES = 16` — размер вектора инициализации

| Функция | Описание |
|---|---|
| `generate_symmetric_key()` | Генерирует криптографически случайный ключ SM4 длиной 16 байт с помощью `os.urandom(16)`. Возвращает `bytes`. |
| `encrypt(plaintext, key)` | Шифрует открытый текст алгоритмом SM4-CBC. Генерирует случайный IV, применяет PKCS7-паддинг для выравнивания длины до кратной 128 битам, затем шифрует. Возвращает `IV (16 байт) + шифртекст`. |
| `decrypt(data, key)` | Расшифровывает данные. Извлекает IV из первых 16 байт, расшифровывает оставшиеся данные SM4-CBC, снимает PKCS7-паддинг. Возвращает исходный открытый текст. |

**Формат зашифрованных данных:**
```
[ IV (16 байт) ][ Шифртекст (N байт) ]
```

---

### 4.3 `asymmetric.py` — RSA-OAEP

Модуль асимметричного шифрования. Реализует генерацию ключевой пары RSA и шифрование/дешифрование данных по схеме RSA-OAEP.

| Функция | Описание |
|---|---|
| `generate_rsa_keys()` | Генерирует пару RSA-2048 с публичным показателем 65537. Возвращает кортеж `(private_key, public_key)`. |
| `_oaep_padding()` | Внутренняя вспомогательная функция. Возвращает объект OAEP-паддинга с MGF1 и SHA-256. Вызывается из `encrypt` и `decrypt`, чтобы не дублировать параметры. |
| `encrypt(data, public_key)` | Шифрует данные открытым RSA-ключом с OAEP-паддингом. Используется для шифрования симметричного ключа SM4. |
| `decrypt(data, private_key)` | Расшифровывает данные закрытым RSA-ключом с OAEP-паддингом. Используется для извлечения симметричного ключа SM4. |

### 4.4 `key_serialization.py` — сериализация ключей

Модуль отвечает за сохранение и загрузку RSA-ключей в файлы формата PEM.

| Функция | Описание |
|---|---|
| `_ensure_dir(path)` | Создаёт родительские директории перед записью файла. |
| `save_public_key(public_key, path)` | Сохраняет открытый RSA-ключ в PEM-файл в формате `SubjectPublicKeyInfo`. |
| `save_private_key(private_key, path)` | Сохраняет закрытый RSA-ключ в PEM-файл в формате `TraditionalOpenSSL` без парольной защиты. |
| `load_public_key(path)` | Загружает открытый RSA-ключ из PEM-файла с помощью `load_pem_public_key`. |
| `load_private_key(path)` | Загружает закрытый RSA-ключ из PEM-файла с помощью `load_pem_private_key`. |

### 4.5 `scenarios.py` — сценарии

Реализует три основных сценария работы системы. Каждая функция принимает словарь `cfg` с путями к файлам из `settings.json`.

#### `generate_keys(cfg)`
Сценарий генерации ключей гибридной системы.

| Шаг | Действие |
|---|---|
| 1.1 | Генерация симметричного ключа SM4 (`symmetric.generate_symmetric_key`) |
| 1.2 | Генерация пары RSA-2048 (`asymmetric.generate_rsa_keys`) |
| 1.3 | Сохранение открытого и закрытого RSA-ключей в PEM-файлы (`key_serialization.save_public_key`, `save_private_key`) |
| 1.4 | Шифрование симметричного ключа открытым RSA-ключом и сохранение результата (`asymmetric.encrypt`, `file_utils.save_bytes`) |

#### `encrypt_file(cfg)`
Сценарий шифрования текстового файла.

| Шаг | Действие |
|---|---|
| — | Загрузка закрытого RSA-ключа и зашифрованного симметричного ключа |
| 2.1 | Расшифровка симметричного ключа закрытым RSA-ключом (`asymmetric.decrypt`) |
| 2.2 | Чтение исходного файла, шифрование SM4-CBC, сохранение результата (`symmetric.encrypt`, `file_utils.save_bytes`) |

#### `decrypt_file(cfg)`
Сценарий дешифрования файла.

| Шаг | Действие |
|---|---|
| — | Загрузка закрытого RSA-ключа и зашифрованного симметричного ключа |
| 3.1 | Расшифровка симметричного ключа закрытым RSA-ключом (`asymmetric.decrypt`) |
| 3.2 | Чтение зашифрованного файла, дешифрование SM4-CBC, сохранение результата (`symmetric.decrypt`, `file_utils.save_bytes`) |

### 4.6 `main.py` — точка входа

Точка входа в приложение. Разбирает аргументы командной строки через `argparse` и вызывает нужный сценарий из `scenarios.py`.

Поддерживаемые аргументы:

| Аргумент | Описание |
|---|---|
| `--settings <path>` | Путь к JSON-файлу настроек (по умолчанию: `settings.json`) |
| `-gen` / `--generation` | Запустить режим генерации ключей |
| `-enc` / `--encryption` | Запустить режим шифрования файла |
| `-dec` / `--decryption` | Запустить режим дешифрования файла |

Флаги `-gen`, `-enc`, `-dec` являются взаимоисключающими — одновременно может быть указан только один.

## 5. Настройка и запуск

### Файл `settings.json`

```json
{
    "initial_file":   "data/plaintext.txt",
    "encrypted_file": "data/encrypted.bin",
    "decrypted_file": "data/decrypted.txt",
    "symmetric_key":  "keys/symmetric.bin",
    "public_key":     "keys/public.pem",
    "secret_key":     "keys/private.pem"
}
```


### Команды запуска

```bash
# 1. Генерация ключей (выполняется один раз)
python main.py -gen

# 2. Шифрование файла
python main.py -enc

# 3. Дешифрование файла
python main.py -dec

# Использование альтернативного файла настроек
python main.py --settings my_config.json -enc
```

Режимы `-gen`, `-enc`, `-dec` полностью независимы и могут вызываться в произвольном порядке.  
Папки `keys/` и `data/` создаются автоматически при первом запуске.
